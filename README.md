# HTML & CSS Projects Collection

A comprehensive collection of static website clones and interactive games built with HTML, CSS, and JavaScript. Each project showcases different web development concepts and UI/UX design patterns.

---

## 📁 Projects Overview

### 🛒 **Amazon**
A static clone of the Amazon e-commerce platform.
- **Location:** `/Amazon`
- **Files:** `index.html`, `style.css`, image assets
- **Features:** Product listing layout, navigation bar, header styling

## 📋 Project Structure

Each project follows a consistent structure:
```
ProjectName/
├── index.html (or game.html)
├── style.css
└── img/ (or IMG/)
    └── (project images and assets)
```
